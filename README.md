# 火花手环管家（BandSpark）

小米手环 9 Pro / 8 Pro 版「抖音火花自动续火」Android 项目。

核心卖点：**人不碰手机，火花照样续** ——

1. **自动模式**：每天在设定时段内随机时间，App 自动打开抖音网页版聊天页，找到好友并发送随机话术，结果推送到手环屏幕；
2. **手环一键续火 + 快捷编辑**：手环上快捷回复「发」立即发送、「换」换一句话术、「情话/简短/随机」切换话术库、手输任意文字即自定义话术并发送；
3. **断火保险**：手环无人响应 10 分钟后自动兜底发送。

自动化内核移植自开源项目 [DouYinSparkFlow](https://github.com/2061360308/DouYinSparkFlow)（MIT License），
将 Playwright 浏览器自动化替换为 Android WebView + JS 注入，逻辑保持一致。

---

## 一、构建

1. 电脑安装 Android Studio（Hedgehog 或更新版本）；
2. `File → Open` 选择本项目 `BandSpark` 目录；
3. 若提示缺少 Gradle Wrapper，按提示生成（或命令行执行 `gradle wrapper`）；
4. `Build → Build APK(s)`；正式发布用 `Generate Signed Bundle/APK` 用你自己的密钥签名。

## 二、微验接入（重要：卡密验证）

本项目的会员验证使用 **微验**（https://app.llua.cn）网络验证，卡密在微验后台生成，
密钥不在 APK 里，无法被反编译破解。

接入步骤：

1. 注册微验 → 后台「软件管理」→ 添加软件；
2. 拿到 `APPID` 和 `APPKEY`，填入 `app/src/main/java/com/bandspark/huohua/WeiYanClient.kt` 顶部常量；
3. 在微验后台把卡密类型设为**天卡/月卡**，并开启**绑定机器码**（防止一张卡多人共用）；
4. 打开微验后台该软件的「API文档」，核对并调整 `WeiYanClient.kt` 里的：
   - `BASE_URL`（接口地址）
   - `login` / `heartbeat` 里的 `act` 动作名与参数名
   - `sign()` 的签名算法（不同版本规则可能不同）
5. 在微验后台「卡密管理」批量生成卡密，在闲鱼/淘宝按张售卖。

**验证流程**：激活时调微验 `login`（卡密+机器码）；日常本地读到期时间（无网也能用）；
每 12 小时后台 `heartbeat` 复核一次，封卡/退卡立即生效；网络异常不影响当天使用。

## 三、使用流程（用户视角）

1. 装 App，点「登录抖音」→ 网页版登录页 → 截图二维码 → 抖音 App「扫一扫→相册」识别（或验证码登录）；
2. 添加好友：输入对方**备注/昵称/抖音号**（备注最准）；
3. 点「立即续火」手动发一次；
4. 输入卡密激活会员 → 打开「自动续火」开关。

## 四、手环端说明（小米手环 9 Pro / 8 Pro）

- 手机需为 Android，且已装「小米运动健康」并打开通知权限；
- 「火花待续」是消息型通知（MessagingStyle + RemoteInput），手环支持快捷回复即可用；
- 若手环对第三方消息不显示快捷回复（部分固件限制），自动降级为“手环提醒 + 10 分钟后自动发送”，核心功能不受影响；
- **手表快捷编辑面板 = 该通知的快捷回复**：发 / 换 / 情话 / 简短 / 随机。

## 五、火花表盘（门面，配合表盘自定义工具）

1. 电脑打开 `tools/spark_face.svg`，导出/截图为 **336×480 PNG**；
2. 手机装「表盘自定义工具」（你已有的 tech.pingx.watchface，支持 9 Pro / N67）；
3. 用它的「照片表盘」功能导入该 PNG 作背景，叠加时间/日期/步数元素，生成表盘并安装；
4. 日常看时间就用火花表盘，续火操作靠 BandSpark 的手环快捷编辑通知 —— 两者配合。

## 七、风险声明

- 自动化操作抖音网页版存在账号被限制/风控的风险，销售时须向用户明示；
- 发送频率刻意限制为每天 1 次、随机时间、随机话术，避免高频触发风控；
- 请遵守《抖音用户服务协议》，合理使用。

## 八、项目结构

```
BandSpark/
├── app/src/main/assets/js/core.js      # 抖音 IM 自动化 JS（移植自 douyin_im.py）
├── app/src/main/java/com/bandspark/huohua/
│   ├── MainActivity.kt                  # 主界面：登录/好友/话术/会员/日志
│   ├── DouyinEngine.kt                  # 自动化引擎
│   ├── DouyinJs.kt                      # JS 调用常量
│   ├── JsBridge.kt                      # 页面→App 回执桥
│   ├── AutoSendService.kt               # 后台前台服务
│   ├── BandReplyReceiver.kt             # 手环快捷回复（发/换/情话/简短/随机/自定义）
│   ├── BandAlarmReceiver.kt             # 每日定时入口
│   ├── BootReceiver.kt                  # 开机重排任务
│   ├── SparkScheduler.kt                # 随机时间调度
│   ├── NotifyHelper.kt                  # 通知中心（手环 RemoteInput）
│   ├── Prefs.kt                         # 配置存储
│   ├── VipManager.kt                    # 会员状态（微验+离线宽限）
│   ├── WeiYanClient.kt                  # 微验网络验证客户端
│   └── MessagePool.kt                   # 分类话术库 + 轮播
└── tools/
    ├── spark_face.svg                   # 火花表盘设计稿（9 Pro 336×480）
    └── keygen.py                        # 【已废弃】离线卡密生成器，改用微验
```
